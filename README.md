# PROG2006 A2 - Firefly Storybook (Lila's First Light)
Unity 2D interactive children storybook, mobile portrait 9:16, WebGL build.

## Links
- GitHub Source Repository: https://github.com//Firefly-Storybook
- Live Demo (GitHub Pages): https://060104-hwb.github.io/Firefly-Storybook/

## Project Info
- Engine: Unity 2022.3 LTS
- Platform: WebGL, mobile vertical screen (Portrait 9:16)
- Function: Page switch button, swipe navigation, click interaction, audio effect

## Folder Structure
- Assets: Unity game source
- Packages: Package config
- ProjectSettings: Unity project settings
- docs: WebGL build for GitHub Pages demo
